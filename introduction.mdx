# Documentation

WizzGift lets you sell gift cards, vouchers, and mobile top-ups in a simple, developer-friendly way.

You can integrate WizzGift using a lightweight iframe or a full API integration.

This documentation is organized to help you choose and implement the right approach quickly.

---

## Get started

If you are new to WizzGift, start here:

- [**Introduction**](/introduction) – What WizzGift is, key concepts, and how this documentation is structured.

---

## Iframe integration

Use the iframe integration if you want a fast, hosted checkout with minimal backend work.

- [**Iframe introduction**](/iframe/introduction) – High-level overview and when to use iframe.
- [**Customization**](/iframe/customization) – Styling options, sizing, and configuration parameters.
- [**Integration**](/iframe/integration) – Step-by-step guide to embedding the iframe in your product.

## API integration

Use the API integration if you need full control of the user experience and server-side logic.

- [**API introduction**](/api-integration/introduction) – Authentication, base URL, and common patterns.

Tools to help you operate WizzGift in production.
